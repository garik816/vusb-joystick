# Freedom USB Joystick — USB HID Gamepad

Восстановление **Freedom Cordless Joystick 2.4** с потерянным радиоприёмником: оригинальный джойстик подключается к ПК по проводу через самодельную плату на AVR и V-USB.

**Прошивка v2.0.0 (экспериментальная)** — ветка \`feat/hid-gamepad-ps3-generic\`. В исходном проекте использовалась библиотека EasyHID от AlexGyver.

## Совместимость

- **Windows / Linux:** стандартный USB HID Game Pad, драйвер производителя не требуется.
- **PlayStation 3:** реализован стандартный USB HID Game Pad для экспериментов с PS3. Консоль может распознать некоторые сторонние HID-контроллеры, но их поддержка зависит от конкретной игры и версии ПО. **Работа на реальной PS3 пока не подтверждена.**
- **Это НЕ DualShock 3:** здесь нет эмуляции протокола Sony, кнопки PS/Home, гироскопа, вибрации, чувствительных к нажатию кнопок, поддержки безопасного режима (Safe Mode) или Bluetooth. Изменение VID/PID на идентификатор Sony само по себе не обеспечит эти функции.
- **USB:** V-USB Low-Speed; передача семибайтового HID-отчёта.

### HID-отчёт

| Байт | Назначение | Диапазон |
| --- | --- | --- |
| 0 | X, АЦП A2 | 0–255 |
| 1 | Y, АЦП A3 | 0–255 |
| 2 | Rx / газ, АЦП A1, инверсия | 0–255 |
| 3 | Ry / поворот рукоятки, АЦП A0 | 0–255 |
| 4 | Hat Switch (нижние 4 бита) | 0–7; 15 — нейтраль |
| 5 | Кнопки 1–8 | каждый бит соответствует кнопке |
| 6 | Кнопки 9–10 | биты 0–1, остальные нули |

Hat Switch: 0 вверх, 1 вверх-вправо, 2 вправо, 3 вниз-вправо, 4 вниз, 5 вниз-влево, 6 влево, 7 вверх-влево. При противоположных направлениях одна ось D-pad становится нейтральной. Остальные четыре бита байта 4 — padding.

USB VID:PID — **16C0:27DC**. Это общий идентификатор V-USB для HID-джойстиков согласно документации, включённой в библиотеку (\`libraries/EasyHID/usbdrv/USB-IDs-for-free.txt\`); это **не идентификатор Sony**. USB report descriptor состоит из 75 байт; входной отчёт — из 7 байт.

### Распиновка (оригинальная плата)

| Назначение | Arduino pin | Порт AVR |
| --- | --- | --- |
| USB D+ / D− | D2 / D3 | PD2 / PD3 |
| Матрица кнопок, строки | D4, D1, D12, D13 | PD4, PD1, PB4, PB5 |
| Матрица, столбцы | D5, D6, D7 | PD5, PD6, PD7 |
| Дополнительные кнопки 7–10 | D11, D10, D9, D8 | PB3, PB2, PB1, PB0 |
| Оси X / Y | A2 / A3 | PC2 / PC3 |
| Газ | A1 | PC1 |
| Поворот рукоятки | A0 | PC0 |
| Индикатор | A5 | PC5 |

**PB4 и PB5 совмещены с матрицей и питанием потенциометра поворота рукоятки.** Прошивка подаёт напряжение на потенциометр, ожидает 2 мс, считывает АЦП и возвращает выходы в состояние матрицы. Во время измерения матрица не сканируется. Без дополнительных диодов аппаратная матрица может давать ghosting при некоторых комбинациях трёх и более клавиш.

Параметры осей (\`min / center / max / reverse / deadzone\`) меняются в \`joystik/joystick_config.h\` без изменения USB-дескриптора.

## Сборка и прошивка

Схема: [KiCad6/joystick.kicad_sch](KiCad6/joystick.kicad_sch). Плата: [KiCad6/joystick.kicad_pcb](KiCad6/joystick.kicad_pcb). В схеме указан **ATmega8-16P** с кварцем **16 MHz**. Нельзя прошивать ATmega8 прошивкой, собранной для ATmega328P/Arduino Uno.

1. Откройте \`joystik/joystik.ino\` в Arduino IDE.
2. Добавьте локальную библиотеку \`libraries/EasyHID\` в папку Arduino libraries.
3. Выберите AVR core, точный микроконтроллер и частоту кварца. Для ATmega8 может понадобиться альтернативный core (например MiniCore).
4. Загрузите прошивку программатором через ISP-разъём J6. Обычного USB bootloader в этом проекте нет.
5. Проверьте fuse-биты внешнего кварца **перед программированием**: неправильные настройки могут лишить МК тактирования.

Для проверки исходников на сборку ATmega328P (без прошивки в ATmega8):

\`\`\`sh
arduino-cli core install arduino:avr
arduino-cli compile --fqbn arduino:avr:uno --libraries ./libraries ./joystik
\`\`\`

**Ограничение платы:** ATmega8-16P при питании 3,3 В и частоте 16 MHz выходит за гарантированные условия эксплуатации по datasheet. Даже если прототип работает, рекомендуется перепроверить питание и частоту перед изготовлением следующей ревизии.

## Тест-план

- **Windows:** откройте \`Win+R\` → \`joy.cpl\`, убедитесь, что доступны четыре оси, 10 кнопок и Hat/POV. Проверьте крайние положения, середину, диагонали и несколько одновременно зажатых кнопок.
- **USB:** несколько минут непрерывного опроса, быстрые движения осей, отсутствие переподключений. Для углублённой диагностики используйте USBPcap/Wireshark.
- **PS3:** подключите напрямую по USB, проверьте распознавание в XMB, затем управление в конкретной игре. Зафиксируйте версию системного ПО, игру и соответствие органов управления. Для включения PS3, кнопки PS и Safe Mode нужен заведомо совместимый контроллер.

Если PS3 не распознаёт этот generic HID, дальнейший шаг — отдельная аппаратная платформа с нативным USB (например RP2040/RP2350) и реализация протокола, совместимого с конкретным типом PS3-контроллера. Просто подмена VID/PID или HID Usage эту задачу не решит.
